# ATRIUM Senda 3.3.2 — 24/11/2026

## Destaques da versão 3.3.2

- **Suíte de testes confiável.** O orquestrador executa as suítes no ambiente sintético correto, sem respostas 402 falsas em documentos, IA, segurança e multi-tenant.
- **Tooltip do topo corrigido.** Os balões de tema e notificações ficam dentro da tela e mantêm a distância do botão.
- **Relatórios com hierarquia editorial.** A view ganhou cabeçalho e título acessível, sem alterar os filtros nem a exportação.
- **Cadastro de membro no Escritório.** A confirmação com QR, código e segredo permanece visível após a criação, sem ser apagada por uma atualização assíncrona.
- **Movimento reduzido respeitado.** O modal do escritório não anima quando o sistema pede movimento reduzido.
- **Primeiro acesso sem campo legado.** O setup não expõe mais `bootstrapRequired`, alinhado ao fluxo sem token de ativação.
- **Edição manual explícita.** A interface de notificações deixa claro que boletins e coleta não são automáticos nesta edição.
- **Cache atualizado para 3.3.2.** A cadeia de entrada e os arquivos alterados usam a nova versão.

## Atualização

1. Faça backup dos dados do escritório.
2. Baixe os instaladores da versão 3.3.2 na [página de releases](https://github.com/ricarossetto/Atrium-Senda/releases/tag/v3.3.2).
3. Confira as somas SHA-256 em `SHA256SUMS.txt` antes de executar o instalador.
