## Material técnico

- `development/`: decisões, roadmap, plano-mestre e gates de maturidade.
- `judicial/`: A1, TOTP, PJe, eproc e conectividade gerenciada.
- `ui-v2/`: contratos de interface, inventário de componentes e auditorias visuais.
- `codex/`: runbooks internos para agentes de desenvolvimento.
- `assets/screenshots/`: screenshots públicos gerados com dados sintéticos para o README.

O conteúdo de `data/`, `.env`, perfis de navegador, certificados, chaves e `artifacts/` é local e não faz parte da documentação pública.
